# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through
GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. You will get
an answer within a few days.

Helpful details: what is affected (code or the hosted endpoint `energie.akquisio.eu`), how to
reproduce it, and what an attacker could achieve.

## Scope

- The code in this repository (latest release).
- The hosted endpoint `https://energie.akquisio.eu/mcp`.

The SMARD data itself and smard.de are run by the Bundesnetzagentur and are out of scope; please
report problems there to them.

Please do not run load tests or automated scanners against the hosted endpoint.
